# Inventory Builder — Fabric 1.21.11 (source prototype)

A client-side Minecraft building assistant that converts **limited keywords** in a description into a local template and places blocks using ordinary player inventory interactions. **This is not a general-purpose AI model**, and image-to-build, hologram rendering, and remote AI integration are **not implemented** in this version.

## Build

Requirements: Java 21, Gradle 8.14+ and network access to Fabric/Maven repositories.

Run `gradle build` in this folder, then look for `build/libs/inventory-builder-0.1.0.jar`. The project is provided as source because a Gradle build could not be verified in this environment. Fabric/Yarn API changes may require adjustments before it compiles.

Install Fabric Loader and Fabric API for Minecraft 1.21.11 and place the built JAR in your `mods` directory.

## Commands

- `/builder create small spruce cabin` — generates a simple cabin template
- `/builder create large medieval castle` — generates a larger castle template
- `/builder preview` — anchors the plan 4 blocks in front of you (text feedback only)
- `/builder materials` — prints the planned block counts
- `/builder start` — begins placement
- `/builder pause` — pauses
- `/builder status` — progress
- `/builder cancel` — discards the placement queue

## Important limitations

- Templates are deterministic, not generated by an AI service. Only basic cabin/house and castle designs exist.
- **No visual hologram** yet: `preview` anchors the plan but does not draw it.
- Blocks must be available in the **hotbar**; items in the rest of the inventory are not moved automatically.
- The player must be within 4.5 blocks of each placement. This is not autonomous pathfinding; walk around the structure and resume.
- Each placement needs a supporting solid face. The builder pauses if there is no support; you may need to place scaffolding manually.
- The world/server can reject placements due to protection, reach, or anticheat. Use only where building automation is permitted.
- Material counts are estimates for the plan, not a subtraction against inventory.
- No blocks are conjured, and the builder does not use `/setblock` or creative inventory.
